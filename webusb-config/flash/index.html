选择硬件版本

请选择与开发板一致的型号。不同板型的 Flash / PSRAM 不同，固件不通用。
当前浏览器不支持 Web Serial。
请使用 桌面版 Chrome / Edge 打开本页面。 本页面必须通过 https:// 或 http://localhost 访问。
首次烧录会询问是否擦除 Flash，选择“擦除”即可（会清除已有配置与蓝牙配对）。

烧录步骤

  1. 确认开发板型号，在上方 “选择硬件版本” 中选择对应板型（N16R8 / N8R2 / N4R2）。
  2. 用 USB 数据线把 ESP32-S3 开发板连接到电脑（建议使用 原生 USB/OTG 口）。
  3. 点击 “连接设备并烧录”，在弹出的串口列表中选择开发板。
  4. 等待进度完成，设备会自动重启。
  5. 烧录完成后，前往 配置中心 连接设备进行按键与蓝牙设置。
串口怎么选：开发板有两个 USB 口。选 UART 口（COM 桥）对应的串口最省事， 它带自动复位电路，可以直接开始烧录；选 原生 USB 口时若无法识别， 请按住 BOOT 键 → 点按一下 RST → 松开 BOOT，再点击烧录按钮。 仍然失败请检查 USB 数据线（需支持数据传输）与串口驱动。
首次烧录会询问是否擦除 Flash，选择“擦除”即可。擦除会清空按键映射与蓝牙配对记录， 但按键映射可以先用 导出 备份成 JSON（配置中心 → 系统设置 → 原始 JSON）。
